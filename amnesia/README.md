# Amnesia

A minimal browser prototype about repeating loops, forgotten experience, and persistent memory notes.

## Run

Open `index.html` in a browser. No build step or dependencies are required.

## Controls

- Move with **WASD** or the **arrow keys**.
- Approach the glowing marker and press **E**.
- Use **Begin next loop** to reset the world.
- Add notes in the memory panel; notes persist through loops using browser local storage.
